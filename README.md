# Vendoo Crosslisting Project

Portable, secret-free operating documentation and tools for preparing Vendoo listings for eBay, Poshmark, and Depop.

Start with:

- `AGENTS.md` for standing Codex instructions.
- `VENDOO_CROSSLISTING.md` for the complete workflow and current handoff state.
- `templates/` for per-item records and marketplace copy.
- `scripts/prepare_photos.sh` for creating upright photo copies.

Listing photos and browser/account state are intentionally excluded from Git.
